# Contributing

Contributions are welcome.

Before opening a pull request:

1. Keep the core deterministic and free of runtime network calls.
2. Do not add telemetry, wallet signing, secret collection, or paid API calls.
3. Add or update tests for behavior changes.
4. Preserve backwards compatibility unless the change is intentionally versioned.
5. Do not submit private keys, seed phrases, API keys, customer data, or confidential evidence.

By contributing, you agree that your contribution may be distributed under the repository's MIT License.
