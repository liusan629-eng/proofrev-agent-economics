# proofrev-agent-economics

Small, deterministic, zero-runtime-dependency utilities for AI-agent commerce and revenue systems.

## What it does

- Distinguishes real externally settled revenue evidence from self-pay, tests, raw HTTP-402 activity, and unmapped activity.
- Computes net contribution margin after supplier, platform, payment, AI-compute, refund-reserve, and other variable costs.
- Applies a strict zero-capital test for customer-funded, referral, atomic-split, post-delivery, and owned-supply structures.
